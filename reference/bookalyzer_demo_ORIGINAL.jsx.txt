# Bookalyzer MVP Specification v1.0

## Status

APPROVED

This document defines the scope of the MVP and serves as the baseline for UI design and development.

---

# Vision

Bookalyzer motivates children to read more books by combining structured reading assessments based on Bloom's Taxonomy, gamification, and meaningful insights for parents.

The application **does not replace books**.

Its goal is to encourage children to progress toward reading complete physical books.

---

# MVP Goal

Validate the following hypothesis:

> Children enjoy completing structured reading assessments, while parents gain valuable insights into their children's reading comprehension.

---

# Platform

Desktop Web Application only.

Mobile applications are out of scope.

---

# Supported Book

Only one book will be available:

**The Little Prince**

The software must be designed so additional books can be added later without code changes.

---

# User Roles

## Child

Reads summaries or physical book.

Completes assessments.

Earns rewards.

---

## Parent

Creates child accounts.

Views progress.

Receives assessment reports.

---

## Administrator

Manages books.

Uploads summaries.

Creates and manages assessments.

Publishes books.

---

# Reading Modes

Every book supports three reading modes.

The child may choose any mode.

No restrictions.

## Mode 1

Short Summary

Purpose:

Quick introduction.

Reward:

5 points

Achievement:

Bronze

---

## Mode 2

Extended Summary

Purpose:

Better understanding.

Reward:

5 points

Achievement:

Silver

---

## Mode 3

Physical Book

The application does not contain the complete electronic book.

The child confirms they have read the physical book.

Reward:

5 points (temporary MVP value)

Achievement:

Gold

Highest recognition.

---

# Reading Assessment

The assessment follows Bloom's Taxonomy.

Question structure is identical across all books.

Only content changes.

Supported question types:

- Multiple Choice
- Ordering
- Matching
- Classification
- Ranking
- Crossword
- Fill Missing Word
- Open Answer

Questions are presented in random order where applicable.

---

# Question Bank

Two question sources are supported.

## 1. Curated Questions

Created by educational experts.

Uploaded by Administrator.

Frozen after approval.

This is the default assessment.

Example:

The Little Prince assessment created by Zaven's team.

---

## 2. AI Generated Questions

Supported by architecture.

Not enabled in MVP.

May be used in future versions.

AI never replaces approved curated content.

---

# Assessment Attempts

Unlimited.

Children may retry assessments at any time.

---

# Navigation During Assessment

Children may:

- Move Next
- Move Previous

Answers remain editable until assessment is submitted.

---

# Assessment Progress

Assessment progress is automatically saved.

If the browser closes, the child may continue later.

---

# Results Screen

Display:

- Overall score
- Correct answers
- Incorrect answers
- Correct explanations (where available)
- XP earned
- Badge earned

---

# Parent Dashboard

Display:

- Books completed
- Reading mode selected
- Overall assessment score
- Bloom Taxonomy breakdown
- Reading history
- Number of attempts
- XP earned

Generate a summary such as:

"Your child demonstrates strong understanding of the story and excellent memory of key events. More practice is recommended in analyzing character motivations."

This summary may be AI-generated internally but should appear as a natural educational insight.

---

# Scoring

Initial MVP scoring:

Each completed reading mode awards:

5 Points

Reward economy will be redesigned later.

---

# Reading Verification

No attempt is made to verify whether the child actually read the physical book.

The assessment itself serves as the verification mechanism.

A child who demonstrates sufficient understanding receives the corresponding score.

---

# Book Library

The homepage displays a library.

Initially:

- The Little Prince (Available)
- Pinocchio (Coming Soon)
- Tom Sawyer (Coming Soon)

This communicates future platform growth.

---

# Child Authentication

Parent creates child profile.

Child logs in using:

- Nickname
- PIN Code

No email required.

---

# Parent Account

One parent account may manage multiple children.

---

# Languages

Platform architecture supports localization.

MVP content is Armenian only.

Additional languages will be added later.

---

Administrator creates a new book using the following workflow:

↓

---

# Product Principles

1. Books come first.
Bookalyzer encourages reading rather than replacing books.

2. Bloom's Taxonomy is the educational foundation.
Every assessment follows the same methodology.

3. Learning over testing.
Unlimited attempts and constructive feedback encourage improvement.

4. Parents receive educational insights, not just percentages.

5. Content is the primary asset.
The platform is designed around books, summaries, and assessments.

6. Start simple.
Features outside the MVP are deferred to future phases.

---

# Out of Scope

The following are intentionally excluded:

- Mobile applications
- Teacher Portal
- Publisher Portal
- AI Reading Companion
- AI-generated assessments
- Payments
- Marketplace
- Friend system
- Chat
- Leaderboards
- Advanced reward economy
- Recommendation engine
- Performance optimization
- Analytics dashboard for publishers

---

# Success Criteria

The MVP is considered successful if:

- Children complete reading assessments.
- Children return to complete additional assessments.
- Parents understand and value the reports.
- The platform motivates children to progress from summaries toward reading complete physical books.
- Administrators can add new books and assessments without software changes.

---

# Phase 2 Candidate Features

- AI-generated assessments
- AI Reading Companion
- Teacher Portal
- Publisher Portal
- Mobile applications
- Advanced gamification
- Personalized recommendations
- Adaptive difficulty
- Social features
- Payment and subscription model

function StarField({ count = 40 }) {
  const stars = Array.from({ length: count }, (_, i) => {
    const seed = (i * 97) % 100;
    return {
      top: `${(i * 37) % 100}%`,
      left: `${(i * 61 + seed) % 100}%`,
      size: 1 + (i % 3),
      opacity: 0.3 + ((i * 13) % 50) / 100,
    };
  });
  return (
    <div className="absolute inset-0 overflow-hidden pointer-events-none">
      {stars.map((s, i) => (
        <div key={i} className="bk-star-dot" style={{ top: s.top, left: s.left, width: s.size, height: s.size, opacity: s.opacity }} />
      ))}
    </div>
  );
}
 
function BadgeDot({ badge, size = 10 }) {
  const cls = badge === "Gold" ? "bk-bg-gold" : badge === "Silver" ? "bk-bg-silver" : "bk-bg-bronze";
  return <span className={`inline-block rounded-full ${cls}`} style={{ width: size, height: size }} />;
}

}

          <h2 className="bk-display text-2xl mb-4">The Little Prince</h2>
          {selectedMode === "physical" ? (
            <div>
              <p className="bk-slate text-sm mb-6 leading-relaxed">
                Bookalyzer doesn't contain the full book — grab your physical copy of
                The Little Prince and read it. When you're done, confirm below.
              </p>
              <label className="flex items-center gap-3 mb-6 cursor-pointer">
                <input type="checkbox" checked={physicalConfirmed} onChange={(e) => setPhysicalConfirmed(e.target.checked)} className="w-4 h-4" />
                <span className="text-sm">I've read the physical book</span>
              </label>
            </div>
          ) : (
            <p className="bk-slate text-sm mb-6 leading-relaxed whitespace-pre-line">
              {selectedMode === "short" ? SHORT_SUMMARY : EXTENDED_SUMMARY}
            </p>
          )}
          <button
            disabled={selectedMode === "physical" && !physicalConfirmed}
            onClick={() => setScreen("assessment")}
            className="bk-btn-dark rounded-lg px-5 py-2.5 text-sm font-medium disabled:opacity-30"
          >
            Start assessment
          </button>
        </div>
      )}
 
      {screen === "assessment" && (
        <AssessmentScreen
          qIndex={qIndex} setQIndex={setQIndex}
          answers={answers} setAnswers={setAnswers}
          onSubmit={() => { setSubmitted(true); setScreen("results"); }}
        />
      )}
 
      {screen === "results" && (
        <ResultsScreen
          answers={answers} selectedMode={selectedMode}
          onDone={() => { resetJourney(); setScreen("library"); }}
        />
      )}
    </div>
  );
}

function OrderingInput({ items, value, onChange }) {
  const move = (idx, dir) => {
    const next = [...value];
    const target = idx + dir;
    if (target < 0 || target >= next.length) return;
    [next[idx], next[target]] = [next[target], next[idx]];
    onChange(next);
  };
  return (
    <div className="flex flex-col gap-2">
      {value.map((itemIdx, pos) => (
        <div key={itemIdx} className="flex items-center gap-2 border bk-border rounded-lg px-3 py-2 text-sm">
          <span className="bk-mono text-[10px] bk-slate w-4">{pos + 1}</span>
          <span className="flex-1">{items[itemIdx]}</span>
          <button onClick={() => move(pos, -1)} className="bk-slate hover:bk-ink px-1">↑</button>
          <button onClick={() => move(pos, 1)} className="bk-slate hover:bk-ink px-1">↓</button>
        </div>
      ))}
    </div>
  );
}
 
function MatchingInput({ left, right, value, onChange }) {
  return (
    <div className="flex flex-col gap-2">
      {left.map((l, i) => (
        <div key={i} className="flex items-center gap-3">
          <span className="text-sm w-40 shrink-0">{l}</span>
          <select
            value={value[i] ?? ""}
            onChange={(e) => onChange({ ...value, [i]: Number(e.target.value) })}
            className="flex-1 border bk-border rounded-lg px-2 py-1.5 text-sm outline-none"
          >
            <option value="" disabled>Choose a match...</option>
            {right.map((r, j) => (
              <option key={j} value={j}>{r}</option>
            ))}
          </select>
        </div>
      ))}
    </div>
  );
}
 
function ClassificationInput({ q, value, onChange }) {
  return (
    <div className="flex flex-col gap-2">
      {q.options.map((opt, i) => (
        <div key={i} className="flex items-center justify-between border bk-border rounded-lg px-3 py-2">
          <span className="text-sm">{opt.label}</span>
          <div className="flex gap-1.5">
            {["A", "B"].map((g) => (

            ))}

}
 
/* ---------- grading ---------- */
function gradeQuestion(q, answer) {
  if (answer === undefined) return 0;
  if (q.type === "mc") return answer === q.correct ? 1 : 0;
  if (q.type === "fillblank") {
    const norm = (s) => (s || "").trim().toLowerCase();
    return norm(answer) === q.answer || (q.altAnswers || []).some((a) => norm(answer) === a) ? 1 : 0;
  }
  if (q.type === "ordering") {
    const correctCount = answer.filter((v, i) => v === q.correctOrder[i]).length;
    return correctCount / q.correctOrder.length;
  }
  if (q.type === "matching") {
    const total = q.left.length;
    let correct = 0;
    for (let i = 0; i < total; i++) if (answer[i] === q.correctMap[i]) correct++;
    return correct / total;
  }
  if (q.type === "classification") {
    const total = q.options.length;
    let correct = 0;
    q.options.forEach((opt, i) => { if (answer[i] === opt.group) correct++; });
    return correct / total;
  }
  if (q.type === "open") {
    const text = (answer || "").toLowerCase();
    return q.keywords.some((k) => text.includes(k)) ? 1 : 0;
  }
  return 0;
}
 
function ResultsScreen({ answers, selectedMode, onDone }) {
  const scores = QUESTIONS.map((q) => gradeQuestion(q, answers[q.id]));
  const overall = Math.round((scores.reduce((a, b) => a + b, 0) / QUESTIONS.length) * 100);
  const mode = READING_MODES.find((m) => m.id === selectedMode);
 
  return (
    <div className="max-w-xl mx-auto">
      <div className="bk-bg-night rounded-2xl p-8 text-center bk-card mb-6 relative overflow-hidden">
        <StarField count={25} />
        <div className="relative">
          <div className={`w-14 h-14 rounded-full mx-auto flex items-center justify-center mb-4 ${mode.badgeClass}`}>
            <Trophy size={22} className="text-white" />
          </div>
          <div className="bk-mono text-[10px] bk-gold mb-2">{mode.badge.toUpperCase()} BADGE EARNED</div>
          <h2 className="bk-display bk-cream-text text-3xl mb-1">{overall}%</h2>
          <p className="bk-cream-slate text-sm">Overall score · +{mode.points} XP earned</p>
        </div>
      </div>
 
      <div className="flex flex-col gap-3">
        {QUESTIONS.map((q, i) => {
          const s = scores[i];
          const correct = s === 1;
          return (
            <div key={q.id} className="bg-white rounded-xl p-4 bk-card">
              <div className="flex items-start gap-3">
                <div className={`w-6 h-6 rounded-full flex items-center justify-center shrink-0 mt-0.5 ${correct ? "bk-bg-sage" : s > 0 ? "bk-bg-gold" : "bg-[#E7B0B7]"}`}>
                  {correct ? <Check size={13} className="text-white" /> : <X size={13} className="text-white" />}
                </div>
                <div className="flex-1">
                  <div className="text-sm font-medium mb-1">{q.prompt}</div>
                  <div className="bk-mono text-[10px] bk-slate mb-1">
                    {s === 1 ? "Correct" : s > 0 ? `Partial credit (${Math.round(s * 100)}%)` : "Not quite"} · {q.bloom}
                  </div>
                  <div className="bk-slate text-xs">{q.explanation}</div>
                </div>
              </div>
            </div>
          );
        })}
      </div>
 
      <button onClick={onDone} className="w-full bk-btn-dark rounded-lg py-2.5 text-sm font-medium mt-6">
        Back to library
      </button>
    </div>
  );
}

                <button onClick={() => { setScreen("list"); resetWizard(); }} className="bk-btn-dark rounded-lg px-5 py-2.5 text-sm font-medium">
                  Back to book list
                </button>
              </div>
            )}
 
            {wizardStep < 6 && (
              <div className="flex items-center justify-between mt-8">
                <button disabled={wizardStep === 0} onClick={() => setWizardStep((s) => s - 1)} className="flex items-center gap-1 bk-btn-outline rounded-lg px-4 py-2 text-sm disabled:opacity-20">
                  <ArrowLeft size={14} /> Back
                </button>
                {wizardStep === 5 ? (
                  <button onClick={publish} className="flex items-center gap-1 bk-btn-primary rounded-lg px-5 py-2 text-sm font-medium">
                    Publish book <Check size={14} />
                  </button>
                ) : (
                  <button onClick={() => setWizardStep((s) => s + 1)} className="flex items-center gap-1 bk-btn-dark rounded-lg px-4 py-2 text-sm">
                    Next <ArrowRight size={14} />
                  </button>
                )}
              </div>
            )}
          </div>
        </div>
      </div>
    );
  }
 
  return (
    <div className="bk-bg-cream min-h-[560px] px-6 py-10">
      <div className="max-w-3xl mx-auto">
        <div className="flex items-center justify-between mb-1">
          <h2 className="bk-display text-2xl">Book Management</h2>
          <button onClick={() => setScreen("wizard")} className="flex items-center gap-1.5 bk-btn-primary rounded-lg px-4 py-2 text-sm font-medium">
            <PlusCircle size={15} /> Add new book
          </button>
        </div>
        <p className="bk-slate text-sm mb-6">Books can be added without any code changes.</p>
 
        <div className="bg-white rounded-2xl bk-card overflow-hidden">
          <div className="grid grid-cols-[1fr_auto_auto] gap-4 px-5 py-3 bk-mono text-[9px] bk-slate border-b bk-border">
            <span>TITLE</span><span>STATUS</span><span></span>
          </div>
          {books.map((b) => (
            <div key={b.id} className="grid grid-cols-[1fr_auto_auto] gap-4 px-5 py-4 items-center border-b bk-border last:border-0">
              <div>
                <div className="text-sm font-medium">{b.title}</div>
                <div className="bk-slate text-xs">{b.author}</div>
              </div>
              <span className={`bk-mono text-[9px] px-2 py-1 rounded-full ${b.status === "available" ? "bk-bg-sage text-white" : "bg-[#EDE6D3] bk-slate"}`}>
                {b.status === "available" ? "PUBLISHED" : "COMING SOON"}
              </span>
              <span className="bk-mono text-[9px] bk-slate flex items-center gap-1">
                {b.status === "available" && <Lock size={11} />} {b.status === "available" ? "LOCKED" : "—"}
              </span>
            </div>
          ))}
        </div>
      </div>
    </div>
  );
}
